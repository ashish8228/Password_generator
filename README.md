#Password Generator
https://passsworddgenerator.netlify.app/

A simple, customizable password generator built using React. This tool allows users to generate secure passwords with a customizable length (5-30 characters) and includes options for uppercase letters, lowercase letters, numbers, and special characters.

Features

Generate passwords of length 5 to 30 characters.

Include uppercase letters, lowercase letters, numbers, and special characters.

Customize the combination of character types in the generated password.
